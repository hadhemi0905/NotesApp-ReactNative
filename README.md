# NotesApp - React Native

Application mobile de prise de notes développée dans le cadre du cours **Atelier Framework Cross-Platform (DSI31)**.

## Fonctionnalités

- Authentification (Email / Password)
- Création, lecture, modification et suppression de notes
- Notes personnelles par utilisateur (isolation via permissions Appwrite)
- Persistance cloud via Appwrite

## Stack technique

- **React Native** + **Expo** SDK 57
- **React Navigation** (Stack)
- **Appwrite** (TablesDB + Auth)
- **react-native-appwrite**
